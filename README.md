## Featured Work

### [Vita Work Backend - Agentic Job Search Platform](https://github.com/Vita-Work/backend)

**AI workflow project**

Designed the backend workflow for an agentic job-search funnel: CV upload, structured profile extraction, clarification questions, preference analysis, profile verification, and search plan generation.

Added embedding-based filtering so the workflow remembers already retrieved jobs, avoids duplicates from previous runs, and searches for new opportunities outside the existing funnel.

Worked with **LangGraph workflow state**, **Gemini structured extraction**, and **DSPy-based verification/planning**.

### [LightGCN Movie Recommendation API](https://github.com/aidin1324/gnn-endpoint)

Graph neural network recommender prototype built with PyTorch Geometric and MovieLens.

Implemented LightGCN-style message passing, user/movie embeddings, diversity-aware recommendation, and a Flask API for serving recommendations from user-provided ratings.

### [AItchy](https://github.com/aidin1324/AItchy)

AI-assisted journaling and self-reflection app.

Worked on the ML/backend side: FastAPI, SQLAlchemy models, mood analytics, OpenAI API integration, and Docker-based setup.

### [Backend Template](https://github.com/aidin1324/backend-template)

Production-oriented FastAPI backend template with structured logging, settings management, SQLAlchemy foundation, ARQ background workers, tests, linting, and pre-commit hooks.
